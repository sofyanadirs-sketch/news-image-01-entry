The World in One Day — a 1024x1024 newspaper front page summing up Friday 13 November 2026 in one image: the Gulf on edge, Ukraine peace talks, Nvidia's CEO out, China's drills around Taiwan, an oil glut, and Microsoft down worldwide. Drawn entirely by a pure-stdlib Python program — no photos, no network, no downloaded images.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024x1024, ~18 KB). In the grader it writes to `/output/entry.png`.
